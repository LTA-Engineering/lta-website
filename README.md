# lta-website

Placeholder website for LTA Engineering. Plain HTML and CSS, no build step.

## Structure

- `index.html`: the page
- `css/styles.css`: styles; colors and fonts are CSS variables at the top
- `images/`: put images here (PNG, JPG and fonts are stored with Git LFS, see `.gitattributes`)

## Preview locally

Open `index.html` in a browser.

## Conventions

- Default branch is `master`.
- Binary assets (PSD, AI, PNG, JPG, fonts, video) are tracked with Git LFS. Run `git lfs install` once per machine.
